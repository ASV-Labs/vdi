# 12_Claims_and_Honesty — Claims and honesty

Every claim in a video is shown by real footage from the same run, sample work is labelled, ad-libs that change a claim go to the owner, and nothing is called final without evidence.

Stages: script, screen, review.

## What this topic covers

- Claim -> proof line -> run
- Real output only
- Sample-work labels
- Overlays and end cards
- Spoken claims without visuals (licence, prices)

## Related topics

`01_Scripting_and_Boards`, `04_Screen_Capture_and_Demos`, `11_Review_and_QA`

# Overview

## The short version

- **Show it or do not say it.** AX-04 said 'MIT License' over the PR page with nothing on screen showing a licence; AX-01 said 'tested templates' with no templates on screen. [AX ax-v5: AX-04 40.2-41.7 s; AX-01 20.1-23.0 s]
- **Real output only, from the same run.** Never fake product output; adjacent beats in one claim share a run id or carry a label. [AX lessons-001: 3.1, 3.2]
- **Label what is a sample.** Sample pages carry 'This is a sample page, not a customer site.'; the AX-04 data file is labelled sample. [AX lessons-001: 3.5] [AX ax-screens-ax04]

## Where this sits in the workflow

Stages: script, screen, review. The rules in `RULES.md` are keyed to these stages, so `vdi_checklist(stage)` and `vdi_brief(...)` in the MCP server can pull them.
